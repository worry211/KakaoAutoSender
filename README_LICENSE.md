# 카톡매크로 판매용 라이선스 운영 메모

판매 앱은 하나의 제품으로 운영한다. Basic/Pro 구분은 없다.

## 보안 원칙
- 구매자 APK에는 라이선스 **검증용 공개키**만 포함한다.
- 라이선스 **발급용 개인키는 절대 APK/GitHub/구매자에게 넣거나 전달하지 않는다.**
- 개인키를 가진 판매자만 유효한 라이선스를 만들 수 있다.
- 라이선스는 기기 코드에 묶이며 만료일/영구 사용 여부를 서명 데이터에 포함한다.
- 앱은 서명을 검증하고 기기 코드가 다르면 실행을 차단한다.
- 판매자용 발급 도구와 개인키는 별도 비공개 보관한다.

## 사진 자동전송
방 설정에서 선택한 사진 URI 권한을 Android SAF로 보존한다. 카카오 알림의 RemoteInput이 이미지 MIME 데이터 입력을 실제로 제공하는 경우에만 글+사진을 한 번의 답장 액션으로 보낸다. 해당 카카오 버전/방이 데이터 RemoteInput을 제공하지 않으면 텍스트만 대신 보내지 않고 실패 처리한다.

이 방식은 카카오톡 비공식 내부 프로토콜을 사용하지 않으며 Android 알림 답장 기능 범위 안에서만 동작한다.
