## 다른 작업을 방해하지 않는 점검

RC5부터 자동 점검/재시도/재시작 복구는 게임·브라우저·다른 앱의 포커스를 빼앗지 않습니다. 기본 상태는 `다른 작업 중 · 점검 대기`이며 예정 점검은 유지합니다. 매니저나 해당 채팅/보이스룸을 앞으로 가져오거나 바탕화면을 30초 이상 유휴 상태로 두면 재개합니다. 게임/영상의 입력이 없더라도 그 앱이 전경이면 계속 대기합니다. 다른 방의 채팅도 자동 점검 시작을 허용하지 않습니다.

방 증거가 없는 진입/재시도 상태에서는 등록된 정확한 공식 OpenChat 링크의 브라우저 화면도 작업 화면으로 인정합니다. 다른 링크나 탭으로 이동하면 다시 대기합니다. 생성/활성 증거가 이미 확인된 상태에는 일반 브라우저 예외를 적용하지 않습니다.

`전체 시작`, `전체 다시 점검`, `선택 방 지금 확인`, 안전 진단을 직접 실행한 경우에는 그 요청을 즉시 처리합니다. 자동 작업 도중 다른 앱으로 전환하면 다음 입력/창 활성화 전에 대기합니다. 대기를 오류나 성공으로 기록하지 않으며 생성시각·48시간 수명·생성 불확실성을 유지합니다. 점검 대기 중 오디오 표시는 마지막 결과이고 새 검증이 아닙니다.

Kakao의 icon-only UI를 가려진 채 정확히 읽을 수는 없으므로 **다른 앱을 계속 사용하는 동안 실시간 음소거 재검증/요청 처리/종료 후 재생성도 지연됩니다.** 만료시각 때문에 게임 화면을 강제로 바꾸지 않습니다. 무인 모니터 OFF 운용은 다른 앱 대신 바탕화면/해당 Kakao 창을 전경에 둔 상태를 사용하세요. Windows 잠금 중에는 계속 입력을 중지합니다.
## 운영과 복구

UI 작업은 단일 실행이고 다중 방은 순차 처리합니다. 오류를 격리하고 약 10초 → 30초 → 90초 → 274초 → 최대 10분 backoff를 사용합니다. 확정할 수 없는 보호/호환성에는 사용자 조치를 안내합니다. 실제 생성 증거가 있을 때만 시작시각을 기록합니다. 최대 5분 건강점검, 47시간 55분 사전점검과 만료 전후 1분 점검이 있으며 타이머 자체는 생성 명령이 아닙니다.

모니터 OFF 운영, Windows 잠금 시 입력 대기, 정상 해제 후 재개, Kakao/앱 재시작 복구와 Windows 로그인 자동실행을 구현했습니다. 물리 모니터 OFF·잠금/Windows 재시작의 종합 실기 시험은 별도 승인 게이트입니다. 한 세션에서 앱 중복 실행을 차단합니다.

`%LOCALAPPDATA%/VoiceRoomManagerWindows/`에 설정/백업/호환성 지점과 회전 로그를 저장합니다. 손상 원본을 보존하며 백업 복구 시 자동관리는 OFF로 시작합니다. 지원하지 않는 schema, 중복 ID, 과도한 파일 크기는 거절합니다. 진단 ZIP에는 방 이름/링크가 들어갈 수 있으므로 공유 전에 확인하세요.

## 검증과 한계

Windows 테스트 **139개 통과**: 상태 머신, 수명, 오류 격리, 재시작/생성 불확실성, 손상된 설정, 안전한 설정 가져오기, OCR 동시성, 실제 컨트롤 fixture와 잘못된 glyph 거절, 100/150/200% 검출. fixture 배율 검증을 실제 다중 모니터 시험으로 간주하지 않습니다.

2026-10-05 대상 PC / Kakao 26.8.1.5315의 실제 관찰:

- RC3 전체 시작으로 browser → preview → 정확한 방 `1` → 실제 생성(10:46 KST).
- RC4 개발 중 명시적 종료 창 자동 확인/닫기 → 실제 재생성(11:27).
- 신규 생성(11:58)은 당시 메뉴 호환성 지점을 사용했습니다. 최종 기본 네 아이콘 메뉴는 실제 안전 진단에서 캘리브레이션 없이 인식됐습니다(12:18).
- 실행 중 스피커 ON → 자동 OFF와 ACTIVE/두 음소거 유지 및 재보호 횟수 증가(12:27). 시험 포인터 강조를 컨트롤에서 옮긴 뒤 확인했습니다.
- 재시작 후 실제 마이크 ON·스피커 ON을 자동 OFF로 전환하고 두 번 확인(12:00). 보호된 기존 방 점검은 약 2.2초(12:05), 약 1.8초(12:18). 해당 PC/화면의 관찰이며 전체 생성 시간 보장이 아닙니다.

최종 바이너리에서 캘리브레이션 없이 신규 생성부터 보호까지 이어지는 종합 run, 다른 계정 요청, 계정별 다중 방 한도, 물리 모니터 OFF/잠금/Windows 재시작, 실제 48시간 만료는 남았습니다. UIA/OCR/glyph/정확한 제목을 확정할 수 없는 버전에서는 대기합니다. native UIA provider가 멈추면 90초 cooperative 제한을 넘길 수 있습니다. CAPTCHA, 보안인증, 잠금, 계정/플랫폼 제한 우회는 구현하지 않습니다. EXE는 unsigned RC입니다.
