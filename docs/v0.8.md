# v0.8.0

Multi-room automation release.

## What changed
- multiple Kakao Open Chat rooms can be saved at the same time
- each room has its own message, interval, enabled state, and daily limit
- daily limit `0` is represented in the UI as **unlimited**
- one global scheduler wakes for the nearest room, then sends every room that is due
- rooms that are due together are separated briefly to avoid reply PendingIntent collisions
- a failed or expired room session does not redirect to another room; that room fails closed while other due rooms continue
- reboot/app-update restoration preserves per-room next-run timestamps where possible
- v0.7 single-room settings migrate automatically into the first v0.8 room profile

## Safety/routing invariant
A profile name alone is never enough to send. `KakaoNotificationListener.sendToRoom()` still requires the profile room to have a verified live reply session or a verified identity-based recovery that resolves to that same room.
