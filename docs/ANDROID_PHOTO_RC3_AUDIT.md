# Android 사진 기능 전체 흐름 점검 — 2.3.19-photo-rc3 / code 50

이 문서는 코드 검수·자동 검사와 실제 카카오톡 실기기 검증을 구분한다. 이 후보를 판매 검증 완료 또는 완벽한 최종본으로 표시하지 않는다. 검사 실행 결과·커밋·서명·APK 해시는 배포물의 `검증기록.json`에 남긴다.

## 한 번에 사용하는 경로

1. 메인 → **사진 전송 설정·권한·도움말**에서 필요한 설정 상태를 확인한다.
2. **사진 여러 방 전송·공통 설정**으로 이동한다. 한 방만 선택하면 한 방용으로도 사용할 수 있다. 방이 없다면 **방 추가·연결·삭제 관리**에서 새 카카오톡 알림과 방 식별을 확인한다.
3. 방 선택 → **선택 방 공통 사진·시간 설정**에서 사진·간격/매일 시각·하루 한도를 저장한다. 사진 순회와 충돌하는 선택 방의 기존 알림 예약은 꺼진다. 다른 방의 문자 예약은 그대로다.
4. **준비 안 된 선택 방 연결**을 누른다. 첫 방에서 현재 방·사진 확인 후 전송 버튼을 학습한다. 이 학습은 사진 한 장을 실제로 보낸다. 이후 방은 화면을 직접 확인하여 준비 연결을 저장한다.
5. 앱의 사진 전송 화면으로 돌아가 **선택 방 1회씩 시험** 또는 **저장한 일정으로 선택 방 반복 시작**을 누른다. 각 방의 진행·요청 시각·한도 상태를 확인한다.
6. 실제 패널 OFF는 별도 최초 연결 설정을 완료한 뒤 그 실행에서 체크한다. 먼저 사진 없는 5초 시험으로 물리 화면 복구를 확인해야 한다.
7. 중지할 때 **사진 여러 방 전송 전체 중지**, 설정의 **사진 예약 전체 중지·화면 복구**, 중지 알림 또는 하드웨어 전원 버튼을 사용한다. 재부팅·앱/서비스 종료 뒤 자동 재개하지 않는다.

사진 키보드만 사용하는 단일 방 경로도 유지한다. 사진 출처는 수신자 선택이 아니며 현재 방을 직접 확인한다. 사진 선택 자체는 보관하지만 전송 티켓·받는 방 확인·실행 중 예약은 복원하지 않는다. 입력창의 작성 중 문구를 함께 전달하지 않는다.

## 자동 검증 범위

- 호스트 회귀 검사: 사진 저장/재진입, 한 번만 전달, 모호한 응답 재시도 금지, 방 식별/미리보기 게이트, 한도/예약, 중지/재시작, 공통 설정, 기존 문자·라이선스 규칙, 버튼 노출, 새 사진 로딩 중 차단, 상태 복사 정보 제한.
- Android API 30·34·35: 네이티브 SPAKE2·페어링 암호화·TLS exporter, 실제 shell UID의 패널 명령/독립 복구 시나리오. 앱/라이브러리 JNI 검사를 수행한다.
- 같은 가상기기에서 설정 허브·사진 순회·공통 사진 설정·패널 연결 화면을 실제 Activity로 열고 필수 버튼 노출·스크롤·하단 버튼 가시성을 확인한다. 상단/하단 스크린샷을 저장한다. UI 검사는 테스트 전용 로컬 인증 상태를 사용하며 운영 서버나 실제 카카오톡에 전송하지 않는다. 빈 페어링 필드 화면의 캡처만 테스트에서 허용하고 배포 앱은 FLAG_SECURE를 유지한다.
- 배포 APK: 기존 상용 인증서·패키지·버전, 운영 서버 주소, shell 진입점 보존, APK/64bit 네이티브 16KB 정렬, 내려받은 파일 해시 확인.

## 남은 실제 휴대폰 확인

실제 카카오톡 사진 미리보기의 접근성 구조·전송 버튼 동작, 수신 방에 사진 한 장씩 도착, 반복 장시간 유지, 일반/오픈채팅 차이, 최초 휴대폰 자체 페어링, 제조사별 물리 패널 OFF/복구, 절전·Wi-Fi 변경은 실기기에서 확인해야 한다. 가상기기 UI와 shell 명령 응답은 이를 증명하지 않는다.

초기 방 열기는 새 알림의 검증된 액션이 필요하다. 이후 같은 프로세스/리스너 세션에서 검증한 열기 액션을 재사용할 수 있지만, Android나 카카오톡이 그 액션을 취소하면 새 알림이 필요하다. 실제 사진 미리보기가 별도 창/지원 구조로 제공되지 않거나 방 헤더를 구분할 수 없으면 전송하지 않는다. 전원 종료·보안 잠금 우회·자동 잠금 해제 전송은 구현 범위가 아니다.

실기기에서는 동의한 시험 방 2곳에 공통 사진 설정 → 최초 준비 → 기본 모드 각 1회 → 반복/하루 한도 → 전체 중지 → 패널 OFF 순서로 확인한다. 이미 보낸 사진의 결과가 불명확하면 재시도하지 않는다. 사용 중 문제가 있으면 설정 허브의 **문제 확인용 상태 복사** 결과와 문제가 생긴 화면을 함께 확인한다.
