# 사진 키보드 시험판 2.3.7 (38)

## 현재 상태

사용자 기기에서 2.3.6의 알림 사진 입력이 없는 것으로 확인됐다. 이번 버전은 알림과 다른 Android 표준 사진 키보드 입력 경로를 실제 구현한다. 카카오톡이 해당 입력창에서 호환 MIME을 알리고 요청을 수락해야 사용할 수 있다. 일반 채팅·오픈채팅에서 실제 사진 도착은 아직 확인하지 않았다.

**물리 화면 OFF 사진 자동 반복 전송은 구현되지 않았다.** 사진 키보드는 화면을 켜고 사용자가 현재 방을 확인해 1회 전달하는 별도 기능이다. 고객용 완성판 또는 기존 자동전송 문제의 확정 해결책으로 안내하지 않는다.

## 구현

- 같은 APK 안의 선택형 사진 전용 키보드와 설정·지원 정보 화면. 루팅, PC, USB, 별도 앱 없이 Android 키보드 설정으로 켠다. 기본 키보드를 강제로 바꾸지 않는다.
- 기존 방 설정에서 선택한 사진을 출처별로 고른다. 목록의 방 이름은 사진 출처이고 수신자가 아니다. 받는 방은 사용자가 카카오톡에서 직접 연 방이다. 앱이 방 이름으로 검색·추정하거나 내부 식별자를 임의 구성하지 않는다.
- 현재 입력창의 패키지, 텍스트 입력 유형, 사진 MIME 지원을 확인한다. 카카오톡 외 앱, 암호·숫자 입력창, 미지원 형식에서는 전달하지 않는다. 플랫폼 MIME과 AndroidX/support-v13 호환 메타데이터를 읽는다.
- 사진 읽기와 축소 미리보기 생성은 별도 작업에서 실행한다. URI 권한·파일·이미지 해독 실패를 표시한다. 큰 이미지는 축소해 미리 본다. 원본 파일은 수정하지 않는다.
- 사용자가 미리보기·현재 채팅방 확인을 체크한 후 눌러야 `InputConnection.commitContent()`를 한 번 호출한다. 읽기 권한 플래그만 전달한다. 키보드 방식은 저장 문구를 넣거나 최종 전송 버튼을 누르지 않는다. 카카오톡 구현에 따라 사진 전달 시 즉시 전송될 수도 있으므로 이를 확인 전에 안내한다. 기존 입력 중인 문구는 사용자가 먼저 정리한다.
- 사진 선택은 30초 후 만료된다. 입력창 재시작, 키보드 숨김·변경, 화면 OFF, 전체 중지는 선택을 무효화한다. 최종 호출 직전에도 라이선스, APK 서명, 잠금, 저장 사진/방 변경을 확인한다.
- 같은 선택은 한 번만 소비한다. 거절·예외·응답 불명확 시 자동 재시도하지 않고 기존 예약 성공 횟수를 늘리지 않는다. 반복·예약으로 키보드를 자동 구동하지 않는다.
- 알림 방식 사진 예약 역시 같은 예약 실행 안에서 최대 1회만 호출한다. 문자 예약의 기존 재시도는 유지한다.
- 진단에는 사진 MIME 목록과 일반 상태 메시지만 기록한다. 입력한 문자, 대화 내용, 수신자, 사진 URI는 기록하지 않는다. MIME 진단은 부팅 변경 또는 15분 경과 시 오래된 상태로 표시한다.
- ‘기존 키보드로 변경’과 사용 설정 안내를 제공한다. 기존 알림 전송·라이선스·방/일정 저장은 유지한다.

## 설치와 시험

1. 기존 앱을 삭제하거나 데이터를 지우지 말고 같은 서명 APK를 덮어설치한다. 실제 업데이트 후 설정 보존은 기기 검증이 필요하다.
2. 기존 자동 예약을 중지한다. 시험용 방·사진만 준비한다.
3. 방 설정 → ‘사진 키보드 설정 · 다른 전송 방식’ → ‘키보드 사용 설정’에서 사진 키보드를 켠다.
4. 카카오톡의 시험용 일반 채팅방을 연 뒤 메시지 입력창을 누른다. Android 키보드 변경에서 ‘카톡매크로 사진 키보드’를 선택한다.
5. 지원 사진 형식이 없으면 버튼이 비활성화된다. 이것이 새 경로의 실제 미지원 결과다. 이미지 형식을 속이거나 텍스트로 대체하지 않는다.
6. 지원되면 사진 출처 → 미리보기 → 현재 방 확인 → 1회 전달을 누른다. 수신 기기에서 원본 이미지 도착 여부를 확인한다. `true` 응답도 수신 증명이 아니다.
7. 오픈채팅에서도 별도로 같은 시험을 수행한다. 일반 채팅 성공을 오픈채팅 지원 증명으로 대신하지 않는다.
8. 사진 준비 중 화면 OFF·잠금·방 변경·전체 중지·사진 삭제·라이선스 만료 시 전달이 없는지 확인한다. 연속 클릭, 카카오톡 거절, 입력창 재연결 시 중복이 없어야 한다.
9. 취소·실패·요청 수락만으로 기존 자동 성공 횟수가 늘지 않아야 한다. 완료 후 기존 키보드로 되돌린다.

## 근거 및 제한

Android의 공식 [Image keyboard support](https://developer.android.com/develop/ui/views/touch-and-input/image-keyboard)는 송신 키보드와 수신 앱 모두 참여해야 하며, 지원 MIME을 광고하지 않는 편집기는 지원하지 않는 것으로 처리하라고 설명한다. 수락 응답은 비동기 로딩 전에 반환할 수도 있고, 사진 전달이 즉시 커밋될 수 있다.

알림 사진 입력과 키보드 사진 입력은 서로 다른 경로다. 사용자 기기에서 후자가 되는지 아직 증거가 없다. 카카오톡이 두 경로 모두 제공하지 않으면 이 버전도 사진 자동전송을 해결하지 못한다. 수정 카카오톡·내부 통신·접근성 UI 자동 조작은 포함하지 않는다.
