# Commercial license implementation

The v1.2 signed offline document/device-code design is superseded by the v2
Worker/D1 one-time key platform. Production contains no legacy verifier or bypass.

See [deployment](COMMERCIAL_DEPLOYMENT.md), [architecture and API](COMMERCIAL_ARCHITECTURE.md)
and [review/validation](COMMERCIAL_REVIEW.md). Preserve the seller's stable Android
release signing key for APK upgrades; it is unrelated to license issuance.
