# 판매용 라이선스 구조

이 앱은 단일 제품으로 판매한다. 등급 구분은 두지 않는다.

## 구매자 APK
- 라이선스 검증 공개키만 포함
- 기기 코드 표시
- 판매자가 발급한 서명 라이선스 문자열 입력
- 라이선스가 유효하고 현재 기기와 일치할 때만 본 기능 진입
- 개인키/발급 기능은 포함하지 않음

## 판매자 전용
- 발급용 개인키를 판매자 기기에만 보관
- 구매자의 기기 코드, 만료일 또는 영구 여부를 넣어 라이선스를 서명
- 개인키가 없으면 유효한 라이선스를 새로 만들 수 없음

## 운영 주의
개인키가 유출되면 제3자가 라이선스를 발급할 수 있으므로 공개 GitHub, APK, 클라우드 로그, 구매자 파일에 넣지 않는다. 유출 시 새 키쌍으로 교체하고 앱의 공개키도 새 버전으로 갱신해야 한다.
