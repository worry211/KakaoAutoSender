# 사진 여러 방 순회 · 2.3.15 (46)

## 구현 범위와 미완료 범위

이번 버전은 **화면을 켠 상태에서 준비한 여러 방을 차례로 열어 사진을 전달하는 경로**와, 관련 설정을 한 화면에 모은 시험판이다. 카카오톡의 실제 알림·접근성 화면·사진 키보드 동작은 기기에서 검증해야 한다. 사용자의 요청에 따라 중간 APK를 반복 배포하지 않고 한 묶음으로 구현하며, 실기기 시험은 뒤로 미룬다.

**실제 디스플레이 OFF/보안 잠금 중 사진을 전송하는 독립 경로는 확보하지 못했다.** 이 버전은 화면이 꺼지면 대기하고, 화면을 켜고 잠금을 풀면 다시 확인해서 계속한다. 이 대기 동작을 화면 OFF 전송이라고 표시하지 않는다. 전송 도중 화면/잠금이 바뀌어 결과가 불명확하면 자동 재시도 없이 전체 순회를 중지한다. 기존 한 방의 ‘화면 꺼짐 시도’ 실험 옵션은 별도로 유지하며 성공을 보장하지 않는다.

## 간소화한 설정

메인 화면 → **사진 여러 방 전송**:

1. 방을 선택하고 **선택 방 공통 사진·시간 설정**에서 기존 일괄 편집 기능으로 사진·간격/매일 시각·하루 한도를 설정한다.
2. **준비 안 된 선택 방 연결**을 누른다. 새 알림에 연결된 방을 차례로 연다. 첫 방은 사진 키보드에서 현재 방·사진을 확인하고 학습을 시작한 뒤, 카카오톡의 마지막 전송 버튼을 직접 한 번 누른다. 이 첫 준비는 실제 사진 한 장을 보낸다. 같은 카카오톡 버전의 버튼 기준이 준비되면 이후 방은 ‘현재 방 연결 완료 · 사진 보내지 않음’으로 방 확인만 하고 넘어갈 수 있다. 다른 방의 미리보기도 최종 실행 때 저장된 버튼 구조와 정확히 일치해야 한다. 완료되면 다음 준비할 방으로 넘어간다. 이미 준비한 방은 건너뛴다.
3. **선택 방 1회씩 시험** 또는 **저장한 일정으로 선택 방 반복 시작**을 누른다. 한 방의 사진 입력·최종 버튼·원래 방 복귀를 확인한 뒤 다음 방을 처리한다. 하루 한도는 실제 상대 수신 횟수가 아니라 전송 요청 시도 횟수다.

순회 때 휴대폰의 카카오톡 화면을 사용한다. 해당 시각에는 방이 자동으로 전환되므로 사용자가 동시에 다른 조작을 하지 않아야 한다. PC 마우스는 사용하지 않는다. 사진 키보드를 현재 입력기로 선택하고 접근성을 허용해야 하며, 이 Android 권한 선택은 사용자가 직접 한다. Android 9 이상에서 새 순회 기능을 사용할 수 있다. 기존 Android 8의 문자/수동 사진 기능은 유지한다.

순회는 **사진만** 전달하며 저장 문구를 사진에 첨부하지 않는다. 다른 방의 기존 문자 예약을 유지할 수 있지만, 선택한 사진 방의 기존 알림 자동전송이 함께 켜져 있으면 시작을 막는다.

## 방 연결과 전송 전 검사

- 방을 열 때마다 현재 확인된 새 카카오톡 알림 연결을 가져온다. 알림의 답장 PendingIntent를 방 열기에 재사용하지 않고, 카카오톡이 만든 contentIntent를 별도로 보존해 사용한다. 알림이 삭제/만료됐거나 방 식별자가 충돌하면 순회를 중지한다. 이전 PendingIntent를 디스크에 저장해 무조건 재사용하지 않는다.
- 최초 준비에서는 확인된 알림으로 방을 연 뒤 새로운 카카오톡 창 전환을 관찰하고, 사용자가 실제로 확인한 방 화면과 최종 전송 버튼을 저장한다. 순회에서는 알림의 영속 식별 정보, 저장한 제목 해시·입력창 ID, 현재 창과 새 창 전환을 확인한 뒤에만 템플릿을 새 창에 결합한다.
- 서로 다른 별칭의 방이 동일한 제목 해시로 구분되지 않으면 두 번째 연결을 거절한다. 같은 제목/아이디만으로 수신자를 추측하거나 좌표로 전송하지 않는다.
- 카카오톡 버전이 달라지면 준비 정보를 사용하지 않고 다시 준비하도록 한다. 설정/사진/라이선스/키보드 연결이 바뀌면 중지한다.
- 작성 중인 문구를 잘못 보내지 않도록 편집기가 비었는지 확인한다. 비밀번호 입력창, 문구가 있는 입력창, 비었는지 알 수 없는 입력창은 사용하지 않는다. 문구를 저장·변경·서버 전송하지 않는다.
- 최종 사진 전송은 기존 PhotoUiWorkflow와 PhotoLoopSession의 미리보기 구조·버튼·원래 방 복귀·할당량·실행 소비 규칙을 사용한다. 같은 실행을 자동 재생하거나 늦은 예약을 몰아서 보내지 않는다.

## 실행·중지·복구

순회 큐는 한 번에 한 방만 실행한다. 알람 실행 ID와 현 실행을 비교하고, 이전 실행의 알람·중지 요청·완료 콜백은 새 순회에 적용하지 않는다. 앱의 전체 중지, 사진 순회 화면의 중지, 알림의 중지, 접근성 종료·라이선스 실패로 중지할 수 있다.

방 준비와 순회 큐 자체는 실행 중인 프로세스/서비스에 속한다. 재부팅·업데이트·프로세스 종료 뒤 자동 전송을 복원하지 않는다. 저장된 최초 준비 정보와 선택 방 설정은 유지하지만 현재 방 검사를 다시 수행한다. 고아 실행 알림은 정리하고 중지 상태로 표시한다.

Android 14 이상에서는 확인된 카카오톡 방 열기 PendingIntent에 송신 측 background activity launch 옵션을 명시한다. OS 또는 카카오톡이 창 열기를 거절하면 확인 시간 제한으로 중지하며, 제한을 우회하거나 화면을 켜지 않는다.

## 검증 근거와 제한

자동 검사는 순회 순서/단발 소비/지연 예약/중지 후 늦은 콜백, 화면 꺼짐 대기와 잠금 해제 후 재예약, 전송 중 화면 변경의 중복 방지, 이전 알람 무시, 고아 실행 정리, 저장한 방 화면 충돌, 카카오톡 버전 변경, 현재 알림·창 열기 액션의 출처 및 삭제 여부, 즉시 1회 전송의 기존 할당량/중복 방지, 빈 입력창 확인을 포함한다. 기존 문자/사진/일괄 설정 테스트도 함께 실행한다.

이는 실제 카카오톡 여러 방의 사진 도착을 검증한 것이 아니다. 현재 연결된 실기기가 없으며, 이 버전의 실제 순회·권한·알림/창 전환·사진 수신은 미검증이다. 판매 지원 범위나 자동 업데이트를 통해 검증 완료로 배포하지 않는다. 화면 OFF 전송까지 포함한 전체 목표는 미완성이다.
