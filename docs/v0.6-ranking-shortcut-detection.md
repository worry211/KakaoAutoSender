# v0.6 ranking shortcut room detection

Samsung/Android conversation notifications can render the KakaoTalk room name from the system conversation shortcut even when `Notification.extras` omits `conversationTitle`, `subText`, and `summaryText`. In that case the notification shade visibly shows the room name while v0.5 diagnostics report no room candidate.

v0.6 reads `NotificationListenerService.Ranking#getConversationShortcutInfo()` (API 31+) and treats the shortcut short/long label as a high-confidence room-name candidate. The shortcut id remains the stable recovery key, but routing stays fail-closed until the user confirms the candidate once.
