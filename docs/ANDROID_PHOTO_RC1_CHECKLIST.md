# KakaoMacro 2.3.17-photo-rc1 (48) — 최종 후보 확인 항목

이 후보에는 공통 사진·시간 설정, 여러 방 예약·반복 순회와 최초 무선 페어링을 통한 패널 OFF 경로가 포함됩니다. 실제 휴대폰 검증은 사용자가 이 최종 후보에서 진행합니다. 자동 검사 성공은 실제 패널 OFF 또는 카카오톡 상대방 수신의 증명이 아닙니다.

## 이번 정리

- 사진 여러 방 전송에서 전체 선택·선택 해제 및 시작 전 첫 미완료 항목 표시.
- 선택한 모든 방의 사진·새 알림·방 식별·최초 준비를 확인한 뒤 패널 제어를 시작.
- 기존 바인딩과 방 식별이 달라지면 최초 준비 대상으로 다시 포함.
- 서버 확인 대기 중 전체 중지·연결 해제·화면 이탈 시 늦게 도착한 실행 콜백 취소. 입력한 포트도 요청 시점 값으로 고정.
- 진행 중 방 선택·공통 설정·중복 시작 제한. 설정 화면의 상태 표시줄·하단 탐색·숫자 키보드 영역 보정.

## 한 번의 실기기 확인 순서

실수로 발송하지 않도록 사진 전송에 동의한 시험 방 두 곳을 사용합니다. 첫 버튼 학습은 실제 사진 한 장을 보냅니다.

1. 기존 앱 삭제 없이 업데이트하고 방·사진·라이선스가 유지되는지 확인합니다.
2. Android 11 이상에서 개발자 옵션 → 무선 디버깅을 켭니다. 분할 화면으로 페어링 창의 포트·코드를 입력해 최초 페어링하고, 기본 화면의 별도 연결 포트로 자체 연결합니다.
3. 사진 없는 5초 시험에서 패널이 실제로 꺼졌다가 돌아오는지 확인합니다. 화면에 검은색만 표시되는 상태와 구분합니다.
4. 사진 여러 방 전송 → 두 시험 방 선택 → 공통 사진·시간 설정 → 준비 안 된 선택 방 연결을 진행합니다. 현재 받는 방을 각각 확인합니다.
5. 화면을 켠 기본 모드에서 ‘선택 방 1회씩 시험’을 실행하고 두 방에 각 한 장이 도착하는지 확인합니다. 저장 문구·작성 중인 문구가 임의로 함께 전송되지 않는지 확인합니다.
6. 패널 OFF 옵션으로 같은 시험을 실행합니다. 화면이 물리적으로 꺼진 채 두 방에 도착하는지는 별도 수신 기기로 확인합니다. 전원 버튼으로 잠근 상태를 자동 해제하는 기능은 없습니다.
7. 공통 간격과 하루 한도를 설정해 반복 실행합니다. 예정 횟수·하루 한도·중지 후 추가 발송 없음·복구 상태를 확인합니다.
8. 서버 확인 중 전체 중지, 최초 준비 취소 후 카카오톡 재진입, 앱의 전체 중지, 알림의 중지, 전원 버튼 잠금, 무선 디버깅 연결 해제를 각각 확인합니다. 결과가 불명확한 사진은 재전송하지 않습니다.
9. 재부팅 후 사진 순회가 저절로 재시작하지 않는지 확인합니다. 무선 디버깅 연결 포트가 바뀌면 다시 연결합니다.
10. 긴 대기·배터리 최적화·Wi-Fi 변경 조건을 확인하고 기종/Android/카카오톡 버전과 결과를 기록합니다.

## 지원 범위

패널 OFF는 휴대폰 내부 카카오톡 UI를 사용하며 기기를 논리적으로 잠금 해제 상태로 유지하는 별도 권한 경로입니다. PC·USB·루팅은 필요하지 않지만 최초 추가 설정과 기기별 지원 확인은 필요합니다. 기기를 전원 종료하거나 보안 잠금을 우회해 전송하지 않습니다.

새 알림 연결이 없는 방·식별 충돌·변경된 미리보기 구조·빈 입력창 확인 실패·연결/라이선스 만료에서는 중지합니다. 앱이나 접근성 프로세스가 종료되면 자동 재개하지 않습니다. API 응답과 화면 복귀 감지는 사진 도착 확인과 구분합니다. 실기기 확인 전 이 기능의 판매 지원을 확정하지 않습니다.
