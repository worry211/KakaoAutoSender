# KakaoMacro 구매자 사용 안내

Windows 1.6.5 / Android 2.3.4 기준입니다. 판매자가 제공한 정식 Release 파일과 SHA-256을 확인하세요. 개발용 debug APK는 구매자 배포 파일이 아닙니다.

## 설치와 첫 인증

Windows는 Windows 10/11 x64에서 `KakaoMacro-PC-v1.6.5.exe`를 실행합니다. 별도의 .NET 설치는 필요 없습니다. 현재 EXE에는 Authenticode 서명이 없어 SmartScreen 경고가 나타날 수 있습니다. 출처가 불분명하거나 해시가 다른 파일은 실행하지 말고 판매자에게 확인하세요. 보안 기능을 전체 해제할 필요는 없습니다.

Android는 판매자가 제공한 서명된 APK를 설치합니다. 기존 정식 앱은 같은 서명으로 업데이트하며, 앱을 삭제하면 저장된 설정과 설치 인증 정보가 손실될 수 있습니다. 알림 접근 권한은 앱 안내에 따라 직접 허용하세요.

판매자가 전달한 **KM 인증 키**를 인증 화면에 입력합니다. 판매자 내부 고객 번호인 **LIC-ID**는 인증 키가 아닙니다. 현재 키 하나는 설치 장치 하나에 연결되므로 Android와 Windows 동시 사용은 별도 라이선스가 필요합니다. 장치 변경은 판매자에게 문의하세요.

## Windows에서 방 연결

1. 카카오톡에서 대상 방을 별도 창으로 열고 메시지 입력칸을 클릭합니다.
2. 앱에 표시된 방 연결 단축키를 누르거나 `+ 방 연결`을 사용합니다. 기본은 `Ctrl+Shift+F8`이며 다른 프로그램이 쓰고 있으면 F9 또는 F10으로 안내됩니다.
3. 등록한 방과 메시지, 반복 간격 또는 예약 시간, 하루 한도를 확인합니다.
4. 같은 제목의 방은 목록의 **방 구분 코드**와 실제 연결한 창을 함께 확인하세요. 코드는 등록 항목 구분용이며 방 제목을 대신하는 전송 주소가 아닙니다.
5. 실행 버튼을 눌러 시작합니다. 중지 버튼은 예약과 대기 중 전송을 중단합니다. 이미 카카오톡에 접수된 전송은 취소할 수 없습니다.

카카오톡이 재시작되거나 창·입력칸·제목이 바뀌면 전송을 차단합니다. 기존 방을 선택하고 **이 방 다시 연결**을 누른 뒤 정확한 방의 입력칸을 클릭하세요. 안내창에서 프로필 구분 코드와 실제 방 제목을 확인하면 메시지·일정·전송 횟수를 유지하며 연결을 교체합니다. 전송은 꺼진 상태로 유지하므로 연결 확인 후 직접 시작하세요. PC를 조작 중이면 예약 전송을 잠시 연기합니다. 프로그램을 재시작해도 명시적으로 다시 실행해야 합니다.

Windows 사진 전송은 지원하지 않습니다. 사진이 설정된 방은 텍스트까지 모두 차단합니다. 텍스트만 사용하려면 **저장된 사진 설정 지우기**에서 제거를 확인한 뒤 직접 시작하세요. 사진 제거만으로 전송이 재개되지는 않습니다. 사진 전송은 Android의 지원되는 알림 답장 기능을 사용하세요.

## Android에서 방 연결

대상 방의 새 카카오톡 알림을 받은 뒤 최근 알림 목록에서 실제 방을 확인하고 연결하세요. 같은 제목만으로 자동 연결하지 않습니다. 알림이 삭제되거나 리스너가 끊기면 실시간 답장 연결을 무효화하므로 새 알림에서 다시 확인하세요. 기존 방 설정과 안전 식별자 복구 규칙은 유지됩니다.

메시지·사진과 시간을 확인한 뒤 실행하세요. 사진 답장이 지원되지 않거나 사진 읽기가 실패하면 텍스트만 대신 보내지 않습니다. 재부팅 후 서버 인증과 새 알림 연결 상태를 확인하세요.

## 자동 저장·설정 복구

Windows 설정 편집은 자동 저장됩니다. 선택한 여러 방을 일괄 편집할 때는 변경할 항목만 체크하세요. `Ctrl+S`로 편집 내용을 바로 저장할 수도 있습니다.

Windows 설정 폴더는 `%LOCALAPPDATA%\KakaoMacro\Windows`입니다. 정상 백업 `settings.json.bak`이 있으면 손상된 `settings.json`을 자동 복구합니다. 두 파일 모두 손상되면 빈 설정으로 덮어쓰지 않고 복구가 필요하다고 표시합니다. 먼저 프로그램을 종료하고 폴더 전체를 별도 위치에 복사한 뒤 판매자에게 문의하세요. 복구 전에 손상 파일을 삭제하지 마세요. 복구해도 전송은 자동 시작하지 않습니다.

X 버튼은 기본적으로 트레이로 숨깁니다. 완전히 종료하려면 트레이의 종료를 사용합니다. 실행 중인 방이 있다면 종료 확인 안내를 확인하세요.

## 오류와 문의

인터넷·서버 연결 오류는 연결을 확인하고 잠시 후 다시 시도하세요. 마지막 정상 인증의 허용 시간이 지나면 자동전송을 안전 중지합니다. 만료·정지·장치 불일치는 판매자에게 라이선스 상태를 확인해야 하며, 재설치만으로 해결되지 않습니다.

문의에는 앱 버전, Windows/Android 버전, 카카오톡 버전, 발생 시간, 화면의 오류 코드·안내, 재현 절차를 제공하세요. 방 이름·메시지·사진·KM 키가 보이는 화면은 가리고 보내세요. 판매자에게 키 전체나 설치 개인키를 보내지 마세요.

## 개인정보 범위

방 이름·메시지·사진은 장치에서 카카오톡 전송을 위해 사용하며 라이선스 backend에 전송하지 않습니다. 서버는 설치 공개키, 라이선스·세션 정보, 앱 버전과 플랫폼, 요청 보호를 위한 최소 정보를 처리합니다. 장치의 방 설정과 사진 참조는 로컬에 저장되므로 공유 PC에서는 사용자 계정과 설정 폴더 접근을 보호하세요. Android 지원 기록은 고정된 상태 분류만 남기며 방 이름·미리보기·사진 경로를 기록하지 않습니다.

카카오톡 공식 제품이 아니며, 카카오톡 UI·알림 구조와 OS 변경에 따른 호환성은 실제 사용 환경에서 확인해야 합니다.

Windows 프로그램은 한 번만 실행할 수 있습니다. 이미 실행 중 안내가 나타나면 기존 창 또는 트레이를 확인하세요. 업데이트 전에는 이전 버전을 완전히 종료하고, 구버전과 신버전을 동시에 사용하지 마세요.
