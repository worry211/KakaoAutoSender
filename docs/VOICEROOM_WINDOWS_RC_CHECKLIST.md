# Windows RC7 최소 실기 승인 체크리스트

Windows v0.4.0 RC7는 release candidate입니다. 아래 실제 관찰과 미검증 게이트를 구분합니다. 날짜/Windows·Kakao 버전/배율/방/결과를 기록하고 실패 시 고급 진단 ZIP을 보관하세요.

## 실제로 관찰한 것 — 2026-10-05 / Kakao 26.8.1.5315

- [x] 전체 시작 → browser CTA → Kakao preview → 정확한 채팅 `1` → 생성 폼 제출 → 실제 전용 창 생성(10:46, RC3).
- [x] 명시적 종료 안내 두 번 확인 → 종료 창 닫힘 확인 → 자동 재생성(11:27, RC4 개발 빌드).
- [x] 생성 후 활성 전용 창에서 매니저 재시작 → 마이크 ON·스피커 ON을 자동 OFF로 전환 → 반복 활성/음소거 검증(12:00, RC4).
- [x] 보호된 기존 방 재점검(12:05 약 2.2초, 12:18 약 1.8초).
- [x] 기본 네 아이콘 메뉴를 캘리브레이션 없이 실제 안전 진단에서 인식(12:18).
- [x] 중단 후 예약 중지, 보이스룸 유지 및 최신 버전 배지/다크 고급 설정을 직접 확인.

## RC5 방해 방지 확인

- [ ] 다른 앱을 전경에 두고 점검 시각 경과: 보이스룸 창이 올라오지 않고 점검 대기 표시. 매니저 복귀 후 실제 활성/음소거 재확인.
- [ ] 게임/영상 앱의 입력이 없어도 전경을 유지하면 창 전환 없음. 무인 운영은 해당 방/매니저 또는 유휴 바탕화면 사용.

## RC6 만료 복구 추가 확인

- [ ] 수정판에서 실제 종료 안내 → 자동 닫기 → 메뉴 자동 선택 → 생성 → 활성/음소거 검증. 실제 48시간 경과 시험과 짧은 종료 시험을 구분.
- [ ] 생성 제출 후 검증 지연/재시작 → 중복 생성 없음 → 자동 관찰로 활성 확인 → 제출 시각 기반 수명 복구. legacy 미기록 시각은 추정하지 않음.
- [ ] 다른 작업 중에는 만료 복구도 대기함. 매니저/해당 방 또는 유휴 바탕화면에서 자동 재개. 완전 백그라운드 입력은 미지원.

## 남은 최소 승인 run

- [ ] 최종 EXE에서 호환성 지점 없이 정확한 이름+링크 → 전체 시작 → 실제 새 생성 → 활성과 두 오디오 OFF까지 한 번에 확인. 기존 활성 run과 신규 생성 run을 구분.
- [x] 실행 중 스피커 ON → 자동 OFF, ACTIVE/두 음소거 유지와 재보호 횟수 증가(12:27, RC4). 시험 포인터 강조를 컨트롤에서 옮긴 뒤 확인. 다른 배율/버전 실기는 남음.
- [ ] 다른 계정에서 실제 스피커 요청 → 차단 또는 거절 결과 확인. 수락/승격하지 않는지 확인. 인식 불가 시 명확한 조치 안내 확인.
- [ ] 두 번째 방과 계정 동시참여 한도: 정확한 방만 처리하고 플랫폼 제한 시 안전 대기하는지 확인.
- [ ] Kakao 종료/재실행, 매니저 종료/재실행, Windows 로그인 재시작 → 저장된 증거 폐기 → 정확한 방/활성/오디오 재확인.
- [ ] 물리 모니터 OFF 운영, Windows 잠금 중 입력 없음, 정상 해제 후 재개. 인증 화면을 통과시키지 않음.
- [ ] 생성 제출 이후 검증 실패/중단/재시작에 추가 생성 없음. 실제 종료를 확인한 경우만 생성 대기 해제.
- [ ] 실제 47시간 55분·48시간: 아직 활성일 때 재생성 없음, 실제 종료 후 생성/활성/음소거 확인.

137개 자동 테스트와 100/150/200% fixture는 위 미검증 항목을 대체하지 않습니다. 모든 승인 게이트를 통과하기 전 판매 검증 완료로 표시하지 않습니다. EXE는 unsigned이며 코드서명/설치 관리자/상용 라이선스를 새로 포함하지 않습니다.
