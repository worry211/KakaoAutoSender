# Windows RC3 최소 실기 승인 체크리스트

이 문서는 Windows v0.4.0 RC3의 **실기 미검증 항목**이다. 성공했다고 사전 체크하지 않는다. 날짜, Windows/Kakao 버전, 배율, 결과를 기록한다. 실패하면 `고급 진단 → 진단 내보내기`를 한 번 수행하고 마지막 단계/필요 조치를 기록한다.

## 한 번의 종합 smoke run
- [ ] 이미 참여한 방의 정확한 이름+링크 등록 → `전체 시작`만 누르기. browser CTA → Kakao preview → 정확한 채팅 → 기존 활성 감지 또는 실제 생성 → PIP/활성 UI를 직접 확인. 다른 방에 생성하지 않았는지 확인.
- [ ] 마이크/스피커 실제 음소거 확인. 일시적으로 켜 봤을 때 guard가 재보호하는지 확인. 상태가 불명확하면 UI가 보호 완료로 표시하지 않는지 확인.
- [ ] 다른 계정에서 실제 스피커 요청 보내기 → 요청 차단 또는 거절 확인. 수락/승격하지 않았는지 확인.
- [ ] 두 번째 방 추가. 지원되면 각각 정확한 방만 처리하는지 확인. 계정 동시참여 제한이 있으면 제한/조치 상태로 멈추는지 확인.
- [ ] 중단을 누른 뒤 자동 클릭/재시도가 없는지 확인. 관리 ON 재개 후 Kakao 종료 → 재실행/정확한 방 회복, 매니저 종료/재실행, Windows 로그인 재시작 회복 확인.
- [ ] 모니터 OFF에서 운영; Windows 잠금 시 입력 중지, 정상 잠금 해제 후 재개 확인. 새 방도 미검증 상태로 조용히 방치되지 않는지 확인.

- [ ] 생성 요청 후 활성 확인 실패를 재현하고 앱 재실행/전체 시작 후 추가 생성하지 않는지 확인. 실제 종료/미생성을 직접 확인한 뒤 생성 대기 해제를 사용하고 정상 재검증 확인.

## 장시간 승인
- [ ] 실제 생성 시각을 기록하고 약 47h55m 점검 및 48h 이후 관찰. 보이스룸이 아직 활성일 때 재생성하지 않고, 실제 종료된 뒤 생성+강한 활성+오디오 재보호가 확인되는지 확인.

출시 판단: 위 항목을 통과하기 전에는 `판매 검증 완료`로 표시하지 않는다. EXE는 unsigned RC다. 이 빌드는 설치 관리자/코드서명/상용 라이선스를 새로 포함하지 않는다.
