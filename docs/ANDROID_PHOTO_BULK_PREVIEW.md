# 여러 방 사진 설정 개선 2.3.9 (40)

사용자 피드백: 사진 키보드·버튼 학습 절차가 어렵고, 여러 방에 한 번에 설정할 수 없으며 실제 작동 여부도 판단하기 어렵다. 이번 변경은 기본 설정과 상태 확인을 간편하게 만든다. **여러 방 사진 자동전송을 새로 완성한 버전이 아니다.**

## 기본 흐름

1. 메인 화면의 ‘여러 방 한 번에 설정’을 누른다.
2. 적용할 방을 선택한다. 전체 선택/해제도 가능하다.
3. ‘같은 사진 선택’으로 사진 한 장을 고른다. 문구·시간·한도도 바꾸려면 해당 항목을 체크하고 입력한다.
4. ‘N개 방에 적용’을 누르면 변경 내용과 사진 자동전송 미지원 방의 일시정지를 확인한 뒤 설정을 저장한다. 전송은 실행하지 않는다.

사진 변경 취소는 기존 방별 사진을 유지한다. 사진 제거는 별도 동작으로 선택한 방에서만 제거한다. 사진을 고르거나 화면을 닫는 것만으로 방 설정을 덮어쓰지 않는다. 회전·화면 재생성 시 입력값과 사진 작업 종류를 유지한다. 사진 정보·파일 확인은 별도 작업에서 수행하며 8초가 지나면 적용하지 않고 중단한다. 읽기 권한 또는 사진 해독에 문제가 있으면 설정을 바꾸지 않는다.

## 상태 안내

- 방 목록에 사진 이름과 ‘사진 자동전송 미지원’, ‘연결 확인 필요’, ‘사진 요청 가능 · 수신 미확인’을 표시한다. 연결된 문자 입력이 있다는 이유로 사진도 지원된다고 표시하지 않는다.
- 사진과 문구를 함께 받지 않는 연결은 별도로 안내한다. 사진만 보내려면 문구도 빈 내용으로 일괄 적용할 수 있다.
- 일괄 저장 뒤 요청 입력 확인·연결/내용 확인·사진 미지원 방 개수를 보여 준다. 수신 완료나 예약 실행 결과를 뜻하지 않는다.
- 사진 일괄 적용 시 현재 연결이 사진을 지원하지 않는 방은 일시정지한다. 사진 설정과 다른 방은 유지한다. 기본 전체 시작에서도 미지원 방을 알리고, 다른 방이 있으면 사용자가 미지원 방을 끈 후 나머지를 시작하도록 선택할 수 있다.
- 예약 실행 시 새로 확인된 사진 미지원 방은 반복 실패시키지 않고 일시정지한다. 문자 예약과 다른 방은 계속 처리한다.
- 사진 요청 수락을 실제 전송 성공으로 표시하지 않도록 목록·테스트·예약 문구를 수정한다. 과거 전송 기록도 현재 설정한 사진의 수신 증명으로 안내하지 않는다.
- 키보드·학습·화면 꺼짐 시험 기능은 방 설정의 ‘고급 사진 기능’ 안에 접어 두었다. 기존 실험 기능을 삭제하거나 지원 범위를 넓히지는 않는다.

## 저장 및 호환성

사진 재정의는 기존 방 프로필과 같은 SharedPreferences의 별도 JSON 키에 저장한다. 사진·문구·일정 변경을 한 Editor.commit에 넣어 관찰자가 일부만 바뀐 중간 상태를 보지 않도록 한다. 기존 `room_media_v1` 사진은 재정의가 없을 때 그대로 읽는다. 사진 제거는 빈 재정의로 기록해 오래된 사진이 다시 나타나지 않게 한다.

같은 사진 URI를 여러 방이 공유할 수 있다. 한 방에서 제거·교체·삭제해도 다른 방이 사용하는 읽기 권한은 유지한다. 마지막 참조가 없어졌을 때만 권한 해제를 시도한다. 사진 캐시는 원본 JSON이 바뀔 때 갱신하고 편집 시 복사해, 준비 중인 일괄 변경이 현재 저장 사진을 건드리지 않게 한다.

## 검증 범위와 남은 제한

기존 테스트에 선택 방만 변경, 사진·문구·일정 동시 적용, 전송 횟수/연결 보존, 공유 URI 권한 유지, 기존 사진 호환·제거 후 부활 방지, 잘못된 URI 차단, 사진 입력 및 문구 지원 판별, 미지원 방만 일시정지, 화면 재생성·취소 시 초안 보존, 저장 관찰자의 일관성을 추가했다.

실제 휴대폰에서의 이번 설정 화면·덮어설치·사진 재부팅 후 접근은 아직 확인하지 않았다. 2.3.7의 사용자 확인은 ‘오픈채팅에서 사진 키보드 전달 후 사람이 카카오톡 마지막 전송 버튼을 눌렀더니 도착함’이다. 2.3.8의 예약·최종 클릭·원래 방 복귀와 화면 OFF 실험은 아직 실기기 검증 전이다. 여러 방 순회 사진 자동전송과 일반 휴대폰의 보장된 화면 OFF 사진 전송은 제공하지 않는다. 설정 화면을 간편하게 한 것을 전송 엔진 완성으로 안내하지 않는다.
